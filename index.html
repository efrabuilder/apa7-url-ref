apa7ref

Pega una o varias URLs y obtén su referencia en formato APA 7, generada aquí mismo, en tu navegador.

01

Solicitud de ficha

La página descarga cada URL a través de un proxy público para evitar restricciones CORS del navegador y lee sus metadatos (autor, título, sitio, fecha). Funciona con páginas web y también con archivos PDF (lee su metadata interna con pdf.js). Algunos sitios bloquean este tipo de acceso o no publican metadatos completos; si eso pasa con un PDF, la ficha con el error te dejará subirlo directamente para generar la referencia sin depender de ningún proxy.

02

Fichero del proyecto

apa7ref / extractor.py

Extracción

Versión Python de la misma lógica que usa esta página: descarga el HTML y busca metadatos de autor, título, sitio y fecha.

apa7ref / formatter.py

Formateo APA 7

Normaliza autor y fecha al estilo APA 7, distingue autores individuales de organizaciones y arma la referencia final.

apa7ref / cli.py

Línea de comandos

Procesa una o varias URLs, lee listas desde archivo y exporta las referencias generadas a un archivo de salida.

tests / test_formatter.py

Pruebas

Seis pruebas unitarias que verifican autor, fecha, organización y cita en texto.

README.md · LICENSE

Documentación

Guía de instalación, uso por CLI y como librería, y licencia MIT.

index.html

Esta página

Reimplementa extractor.py y formatter.py en JavaScript y usa pdf.js para leer metadatos de páginas web y de archivos PDF.
