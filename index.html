apa7ref

Pega una o varias URLs y obtén su referencia en formato APA 7, generada aquí mismo, en tu navegador.

01

Solicitud de ficha

La página descarga cada URL a través de un proxy público para evitar restricciones CORS del navegador y lee sus metadatos (autor, título, sitio, fecha), que luego se formatean a APA 7 con reglas fijas. Funciona con páginas web y también con archivos PDF (lee su metadata interna con pdf.js). Algunos sitios bloquean este tipo de acceso o no publican metadatos completos (por ejemplo, YouTube muestra con frecuencia una pantalla de aviso de cookies en vez de la página real, y publica el autor y la fecha con microdatos que el modo extractivo apenas empieza a soportar); si eso pasa con un PDF, la ficha con el error te dejará subirlo directamente para generar la referencia sin depender de ningún proxy. Si un sitio sigue sin funcionar, el modo Manual te deja escribir los datos directamente.

En este modo, la página descarga cada URL igual que en el modo local (mismos proxies, misma lectura de PDFs), pero en vez de aplicar reglas fijas, le envía los metadatos encontrados — y un fragmento del contenido de la página como contexto adicional — directo desde tu navegador a la API de Anthropic, usando tu propia clave, para que arme la referencia APA 7 final. Esto ayuda con casos ambiguos: autores organizacionales, fechas incompletas o metadatos faltantes que las reglas fijas no siempre resuelven bien. Tu clave no pasa por ningún servidor de apa7ref ni se guarda en ningún lado; se pierde al recargar la página. El uso tiene el costo que aplique tu cuenta de Anthropic.

Escribe los datos de la fuente a mano y la página arma la referencia APA 7 localmente, con las mismas reglas de formato que el modo extractivo (sin descargar nada ni usar ningún proxy). Útil para fuentes que los otros modos no logran leer, como videos de YouTube, contenido detrás de un muro de pago, o páginas que bloquean el acceso automatizado.

02

Fichero del proyecto

apa7ref / extractor.py

Extracción

Versión Python de la misma lógica que usa esta página: descarga el HTML y busca metadatos de autor, título, sitio y fecha.

apa7ref / formatter.py

Formateo APA 7

Normaliza autor y fecha al estilo APA 7, distingue autores individuales de organizaciones y arma la referencia final.

apa7ref / cli.py

Línea de comandos

Procesa una o varias URLs, lee listas desde archivo y exporta las referencias generadas a un archivo de salida.

tests / test_formatter.py

Pruebas

Seis pruebas unitarias que verifican autor, fecha, organización y cita en texto.

README.md · LICENSE

Documentación

Guía de instalación, uso por CLI y como librería, y licencia MIT.

index.html

Esta página

Reimplementa extractor.py y formatter.py en JavaScript, usa pdf.js para leer metadatos de PDFs, y puede pedirle a Claude (con tu propia clave) que interprete casos ambiguos.
